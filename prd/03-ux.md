# 03. 投入と閲覧

> 本章の内容は**全て計画**（実装は未着手）。

## 1. 投入口

**画面上の投入口は1つだけ。** 経路は3つあるが、すべて同じ口に集約し、同じ API に落ちる。

| 経路 | 操作 | 主な端末 |
|---|---|---|
| ペースト | 投入口にフォーカスして `Ctrl`/`⌘` + `V` | Windows / MacBook |
| ドラッグ&ドロップ | 画像ファイルを画面に落とす | Windows / MacBook |
| ファイル選択 | ボタンから選ぶ（`accept="image/*"`） | **iPhone**（後述） |

### 判別

貼られた中身を見て `kind` を決める。人間に選ばせない。

- ペースト時は `ClipboardEvent.clipboardData` を見て、**画像ファイルが含まれていれば `image`**、
  なければテキストとして扱う。
- D&D 時は `DataTransfer.files` を見る。画像以外のファイルは**受け付けずエラー表示**する
  （任意ファイルは対象外。[README](./README.md) §スコープ）。

### 保存のタイミング

- **画像は投入した瞬間に保存する。** 確認ダイアログも保存ボタンも挟まない。
- **テキストは明示的な確定操作で保存する**（`Ctrl`/`⌘` + `Enter`、または送信ボタン）。
  入力途中の文字列を保存し続けることはできないため、ここだけは確定操作が要る。
  「即保存」の趣旨は**画像に確認ステップを挟まないこと**であり、テキストの確定操作はそれと矛盾しない。

### iPhone での経路

**iOS Safari ではペーストによる画像取得が安定しない**ため、**ファイル選択が主経路**になる。

- ファイル選択ボタンは、デスクトップでも常に見える位置に置く（iPhone だけの特別扱いをしない）。
- ペースト・D&D が使えない端末でも、**投入口の見た目と操作の流れは同じ**にする。

### エラー

- 20MB 超過（[02](./02-data-model.md) §5）→ 「20MB を超えています」と表示し、保存しない。
- 画像以外のファイル → 「画像とテキストのみ扱えます」と表示し、保存しない。
- 保存失敗 → 投入した内容を**画面から消さない**。貼り直しを強いない。

## 2. 一覧

**新しい順の時系列のみ。** 検索・タグ・絞り込みは持たない（[05](./05-roadmap.md) §未実装）。

- **50件ずつ**読み込む。
- 受け渡し用途では目的のものは大抵一番上にあるため、**最上部が最新**であることを最優先にする。
- 各エントリに表示するもの: 中身のプレビュー、作成時刻、操作（コピー / ダウンロード / 削除）。

### プレビュー

| 種別 | 表示 |
|---|---|
| テキスト | **プレーン表示**（等幅）。Markdown としてレンダリングはしない。長いものは折りたたみ、展開できる |
| 画像 | **原寸を CSS で縮小**して表示。クリックで原寸表示 |

**Markdown をレンダリングしない理由**: 貼るのは受け渡し対象の文字列そのものであり、
整形されると「元の文字列が何だったか」が分からなくなる。**貼ったものがそのまま見えることを優先する**。

**サムネイルを生成しない理由**: 実装と失敗時のフォールバックを MVP に持ち込まないため
（[05](./05-roadmap.md) §未実装）。回線で重いと感じたら後から足す。

## 3. 取り出し

別端末で受け取るための操作。**一覧から1操作で完結する**こと。

| 種別 | 操作 |
|---|---|
| テキスト | **コピー**ボタン（クリップボードへ）。押したことが分かるフィードバックを出す |
| 画像 | **ダウンロード**ボタン（`Content-Disposition: attachment`）。iPhone では画像長押しでも保存できる |

## 4. 削除

- **確認ダイアログを挟む。** 投入は確認なしで即座に通す代わりに、**破壊操作だけは守る**。
- 削除するとエントリと画像の実体の両方が消える（[02](./02-data-model.md) §3）。復元はできない。

## 5. レスポンシブ

Windows / MacBook / iPhone のいずれからも使う。daisyUI + Tailwind のユーティリティで
**同じコンポーネントを幅で出し分ける**（別画面を作らない）。
