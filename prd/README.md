## 目的

手元の複数端末（Windows / MacBook / iPhone）の間で、**テキストと画像を気軽に貼って、
すぐプレビューできる個人用の共有ツール**。

これまではチャットサービスのメッセージ欄に画像を貼って端末間の受け渡しに流用していたが、
本来の用途ではないため表示できなくなることがあった。**受け渡しそのものを目的とした最小の道具**を自前で持つ。

## 決めるべき論点（grill の入力）

1. **扱うデータ** — テキスト / 画像 / 任意のファイル。どこまでを MVP に入れるか。
2. **投入 UX** — ペースト（Ctrl+V）/ ドラッグ&ドロップ / ファイル選択 / 共有シート。
   **iPhone Safari からの貼り付け**が成立することが要件になりうる。
3. **保存先** — DB 直（BLOB）/ オブジェクトストレージ / ローカルファイル。容量上限と保持期間。
4. **ライフサイクル** — 貼ったものは残るのか、消えるのか。手動削除 / 自動失効 / 件数上限。
5. **認証** — 前段プロキシ（Cloudflare Access 等）に寄せるか、アプリ側にも認証を持つか。
   **個人利用のみか、URL を他人に渡して共有する用途があるか**で結論が変わる。
6. **一覧・検索** — 時系列で並べるだけか、検索・タグ・ピン留めが要るか。
7. **技術スタック / 構成** — 既存リポジトリ（`seseraki` / `highscore-must-fall`）の
   pnpm monorepo + Hono + React/Vite 構成を踏襲するか、規模に対して過剰か。

## 秘匿方針（公開リポジトリ）

本リポジトリは**公開**であるため、PRD にも以下を持ち込まない:

- 秘密情報（`.env*`・API_KEY・DB 資格情報・session cookie の値）。
- 本番/開発の具体情報（ドメイン・TLS・接続先・リバースプロキシ構成）。PRD は**姿勢のみ**記述する。
- **このアプリに実際に貼り付けた内容**。動作確認の証跡は差し支えのないダミーで残す。

非公開の運用情報は gitignore 対象の `.claude-personal/` に置き、「存在すれば参照」する。
