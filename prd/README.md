## 目的

手元の複数端末（Windows / MacBook / iPhone）の間で、**テキストと画像を気軽に貼って、
すぐプレビューできる個人用の共有ツール**。

これまではチャットサービスのメッセージ欄に画像を貼って端末間の受け渡しに流用していたが、
本来の用途ではないため表示できなくなることがあった。**受け渡しそのものを目的とした最小の道具**を自前で持つ。

設計の主眼は次の 3 つ:

1. **貼る手数を最小にする** — **テキストの入力欄を作らない**。貼られた中身を見てテキストか画像かを
   自動で判別し、**確認も確定操作もなく即座に**1エントリとして増える（[03](./03-ux.md) §1）。
   取り出しも**カードをクリックするだけ**でクリップボードに入る（[03](./03-ux.md) §3）。
2. **どの端末でも同じように使える** — Windows / MacBook はページへのペーストと D&D、
   **iPhone は「貼り付け」ボタン**（iOS Safari はページに `paste` を配らないため）。
   どの経路も同じ判別・保存の流れに集約する（[03](./03-ux.md) §1）。
3. **溜まっても壊れない** — 貼ったものは自動で消さない。消すのは自分の意思による削除だけ
   （[05](./05-roadmap.md) §確定事項）。

## スコープ

- **MVP（[05](./05-roadmap.md) Phase 1）**: cookie セッション認証 / テキスト・画像の投入 /
  新しい順の一覧とプレビュー / コピー・ダウンロード・削除。
- **[05](./05-roadmap.md) Phase 2**: 一覧の規模表示 / **共有トークン** —— ログインできない受け手
  （LLM のセッション）へ、**選んだものだけ**を期限付きのリンクで渡す（[04](./04-auth-and-privacy.md) §3.1）。
- **やらない（阻害しないだけ）**: 検索・タグ・自動失効・サムネイル生成・任意ファイル・
  **他者への人間向け共有**・**共有中のものの管理画面**。
  いずれも「後から足せる形にしておく」ことだけを設計上の要件とする（[05](./05-roadmap.md) §未実装）。

## アーキ概観

- フルスタック TypeScript の pnpm monorepo: `packages/{web,server}` の2つ（[01](./01-architecture.md) §2）。
- MySQL 8.4 / Hono(RPC) / Drizzle ORM / React 19 + Vite + TanStack Router + TailwindCSS v4 + daisyUI。
- 画像の実体は **SeaweedFS（S3 互換）**、メタデータは MySQL（[02](./02-data-model.md)）。
- 認証は**アプリ側の cookie セッション**。前段プロキシに依存せず単体で公開できる（[04](./04-auth-and-privacy.md)）。

```
  [ ペースト / ドラッグ&ドロップ / ファイル選択 ]  ← 3経路とも同じ投入口へ集約
                     │  text か image かを web 側で判別し、同一 API へ
                     ▼
   web (UI) ──fetch /api──> server (Hono) ──> MySQL      （メタデータ）
                                        └──> SeaweedFS  （画像の実体・S3 互換）
```
